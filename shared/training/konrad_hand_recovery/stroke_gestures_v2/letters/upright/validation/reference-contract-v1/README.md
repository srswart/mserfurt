## Reference registry and consumers

`snapshot-001/registry.json` records four actual-ink anchors: n, u, m and placed mu.
Each carries its image/file/pixel hashes, owner review, candidate, fixture/text/
placement, physical frame, DPI, source code, fixed tool/action settings and base
sampling/timestep. All anchors are explicitly **candidate-derived**, never
independent style references. The analytic comparator retains its separate
candidate-free provenance and unchanged historical 0.05/0.75 limits; it is not
historical-hand validated or owner-endorsed as the desired style.

Reusable API: `scripts.upright_reference_contract`.

- `load_registry(path, expected_sha256)` requires a consumer-supplied pin and validates the registry against live source/approval bindings.
- `compare_reference(reference, pixels, context)` returns match/mismatch/incompatible for a reference from that validated registry. Do not bypass the loader with untrusted dictionaries.
- `classify_record(record)` separates the frozen historical decision categories; malformed, incomplete or nonfinite evidence makes channels invalid. Its input must come from the verified archive, not an untrusted caller's claimed measurements.
- `build(directory)` publishes a new immutable registry/protocol/freeze/report snapshot; an existing directory is never overwritten.
- `inspect(directory, expected_report_sha256)` requires an external report pin and recomputes decisions, protocol preflight, original source bindings and local artifact hashes without writing or rendering.

Exact regression compares full RGB uint8 pixel arrays, not PNG metadata. A single
changed pixel is a mismatch; a different candidate, code, fixture, frame, tool,
DPI or refinement is incompatible. `quality_pass` is null and
`generalization_proven` is false even for exact matches. We have **not** moved
the old 0.05 limit to a new appearance reference. Variant tolerance remains unset.
Human appearance approval is bound to the saved output, not supplied by this API.

## Validation and evidence

The snapshot compares four approved anchors against six archived workers (seeds
7/19/41, first/replay): 24 exact replay comparisons. Eight new in-memory mutation
controls cover single-pixel change, image shift, crop, tool, frame, candidate,
fixture and false independent provenance. These are contract tests, not fresh
physical versions of H021's eleven negative controls.

Source/artifact verification includes the original 1,256 archived files, pinned
independent inspection, diagnostic report and exact owner contract/appearance
records. Motion channels reclassify the prior verified measurements; this module
does not independently reconstruct raw motion or execute the old renderer again.
The separate snapshot inspector verifies the three new frozen artifacts and
reconstructs the contract report. Zero controller executions, raster renders and
optimization evaluations. Native approved examples remain in [the gallery](../index.html).

## Prepared held-out placement protocol

`snapshot-001/protocol.json` freezes a **prepared, not execution-authorized** next
protocol. Known regressions are n/u/m/mu; text-disjoint held-out placements are
**un, nu, um, nn, uu and mm**, each shifted by `[0.017, -0.011]` in the existing
normalized construction coordinates. These are fixed placement/interletter-air
probes, not context adaptations, joined words or spacing-design targets.

Plan-only preflight checks all six at base, finer arc, finer time and exact
internal subdivision (24 plans), preserving contact topology and full-frame
containment. This is not held-out actual-motion evidence or appearance approval.
Derived nominal references for unseen pairs are explicitly unreviewed; existing
owner KEEP does not automatically extend to them.

The protocol keeps existing mechanical criteria, frame, local padding, seeds and
physical controls. It proposes a **new** cap of 5,000 renders/1,800 seconds per
seed including fresh-process replay, zero retries and zero fitting. That cap is
not yet authorized and does not reuse old allowances. Before scoring, bind a new
execution authorization and freeze execution code, derived reference artifacts
and the independent reader. Held-out actual appearance remains a later review;
no repeat approval of the reference-contract design is needed.
